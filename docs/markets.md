# AIQUANT 市场研究

首版采用日频／延迟数据，覆盖 A 股、港股、韩股、日股、美股、美债、全球国债、宏观政策、交易观察和交易推荐十个栏目。行情、新闻与研究结论都必须有真实来源。来源获确认不等于适配器已经接通；数据缺失时页面明确显示待接入，不使用模拟行情填充。

## 入口与数据流

- `/markets`：观察清单、美国国债期限结构、宏观指标、四因子风险矩阵与证据。
- `/markets/portfolio`：个人多头股票持仓、分币种估值、集中度与风险预算。数量和成本只在浏览器内处理，显式保存后留在该浏览器；不会发给后端或模型。支持删除、清空与导出，不作汇率换算。
- `/markets/trades`：带条件、失效点与期限的研究，以及价格均线观察。没有来源数据时不生成推荐。
- `/admin/markets`：管理员导入核验过的 JSON 快照、预览后发布，或选择美国财政部／日本财务省／ECB／纽约联储／美联储 H.4.1／AKShare／yfinance 发起采集任务。人工发布是完整替换；先保留需要继续公开的旧记录。采集器按标的、来源与观测日期合并，不覆盖其他来源。
- `/api/v1/markets`：匿名只读快照，经过 `packages/backend/src/publication/module-data.ts` 统一公开读取层。

站点声明在 `site/modules/`，实现位于 `modules/markets/`。公开页面只经 HTTP 读取 API，不直接连接数据库；打开页面不会抓取行情或调用模型。管理员写入有会话、CSRF、大小限制、严格校验和审计。

## 来源真实性与时间

数值只能来自获授权的原始数据或经人工核验的原始披露，必须填写来源名、原文链接、观测时点与可用时点。JSON 格式校验只能检查结构、口径和时序，不能证明来源网页确实包含该数字；管理员发布前必须逐项核对，不允许模型补缺。新闻和摘要展示原文链接，不默认转载全文。

美国财政部 XML 适配器读取 2、5、10、30 年名义常期限收益率，单位 `%`。它是官方估计收益率曲线，不是某只国债的可成交价格。环比用基点表达；`asOf` 的零时刻仅承载官方观测日期，不代表盘中成交时间。XML 缺少可靠的逐条官方发布时间，因此 `publishedAt` 使用本次抓取确认可用时刻，并标注 `availabilityBasis: "retrieved"`；不能把这个字段误称为官方发布时间。来源链接指向对应月份的官方 XML。

日本财务省适配器读取官方 CSV 的 10 年固定期限收益率，保留三位小数、百分数单位与来源链接，观测时间为 15:00 JST，次一营业日发布；可用时间保守采用抓取确认时刻。

纽约联储的 [SOFR](https://markets.newyorkfed.org/api/rates/secured/sofr/last/5.json) 和 [EFFR](https://markets.newyorkfed.org/api/rates/unsecured/effr/last/5.json) 官方 API 各读取最近五次观察，进入 `macro` 而非可交易行情。单位为百分数、营业日日频；保留 API 的有效日期、修订／脚注标记、来源链接和[使用条款](https://www.newyorkfed.org/privacy/termsofuse)要求的归属与免责声明。它们是参考利率，不是实时融资报价，不生成风险阈值。

美联储适配器读取 [H.4.1 当前发布](https://www.federalreserve.gov/releases/h41/current/default.htm)中的总资产与存款机构准备金，严格选择周三余额列，排除相邻的周平均、变化额和合并抵消列。单位是百万美元，频率是周频。官方通常周四发布，本系统保守采用实际抓取确认时间；`asOf` 零时刻只承载观测日期。数据使用遵循[美联储网站说明](https://www.federalreserve.gov/disclaimer.htm)，保留出处，不经过 FRED。这里只提供两个宏观序列，不声称接入整套 H.4.1。

宏观记录按 `sourceId + metric + asOf` 合并，相同值保留首次确认可用时间，修订值记录本次确认时间；最多保留最近 500 条观察。`publishedAt` 标记 `retrieved` 时不能当作官方发布时间，也不把新取得的历史数值当作历史上已经可知。宏观指标不进入持仓估值、股票均线或自动交易研究。

其他市场没有获授权的报价接入时保持空缺。ECB 已接入 AAA 10 年即期合成曲线（连续复利），保留原始观测精度，仅作宏观信息展示；服务端禁止用这个标的创建交易研究，不能冒充某个国家国债价格。SEC 持仓披露具有时滞，不能当作当前全市场仓位。具体来源与覆盖见 [来源清单](market-sources.md)。

## 四因子与交易研究

四因子为估值透支、机构集中、宏观流动性、题材全民化。每个市场／因子需明确指标、单位、比较方向、阈值与规则版本，再提供同口径、已发布、未过期的证据。尚未用金融金标样本校准，默认不填阈值、不填“已触发”，更不把缺失当安全。同一时点证据冲突时停止判定。股票估值和产业题材规则不套到国债；国债独有的久期、主权与汇率风险尚未做完整量化。

流动性观察展示同日 SOFR 与 EFFR 的基点差，以及有相邻周三数据时的 H.4.1 余额变化。它们提供可复核的原始观察，不自动转成风险触发结论；缺少可比观察时标明原因。

政策情景研究由 worker 从最近 30 天已公开精选中取材，逐条绑定原文和原文摘要的逐字摘录。模型只能给出未来的条件假设、验证条件与失效条件，不能编造报价、收益率、目标价或执行指令。宽基与国债标的是本站观察范围，不代表原文的推荐。研究最迟七天内复核；重复使用同一模型回执不会刷新生成日期和复核期限。来源撤回、不再精选或摘录改变后，公开接口立即隐藏对应研究。

行情频率和最后观测日期均可见。持仓估值与均线观察使用 7 天的数据质量窗口，这只是暂停陈旧计算的上限，不是实时承诺或投资期限。均线要求至少 61 个有效观测值；股票必须明确复权口径。20／60 观察值交叉仅为未回测研究，未纳入交易成本，不能等同买卖指令。交易日历尚未按交易所校准；稀疏数据被暂停。

个人持仓只对目录中有有效价格的股票估值。指数点位和债券收益率不能乘持仓数量当市值。不同币种分别汇总，缺价会使相应币种组的集中度未知。风险预算由用户自己输入账户资金、单笔风险比例、入场、止损与手数，不预设风险偏好，不自动下单；跳空损失可能超过测算。

## 导入与运行

快照字段见 `modules/markets/domain.ts`，严格校验见 `backend/validation.ts`。导入字段为 `{ schemaVersion: 1, asOf, quotes, evidence, rules, history, ideas, macro }`。所有数组允许为空；已有版本 1 快照缺少 `macro` 时，公开读取返回空数组而不重写原始存储。证券代码必须属于 `sources.ts` 中的目录；个人持仓和密钥不能写入公开快照。发布接口需要 `{ snapshot, reason }`，`reason` 是人工核验说明。

官方采集仅在 API 和 worker 都配置 `COLLECT_ENABLED=true` 时可运行。开发与测试保持关闭，模型调用和推送受独立开关约束。后台按钮发起一次队列任务，提交成功不等于采集成功；需核对任务日志和快照。`POST /api/admin/markets/collect` 接受 `reason` 及可选 `source`：`treasury`（默认）、`japan-mof`、`ecb`、`nyfed`、`fed`、`akshare` 或 `yfinance`。

`MARKET_SERVER.schedules` 为七个已接入来源分别注册 `markets.collect.<source>`，每天上海时间 08:00、18:00 入队一次。仅字面值 `COLLECT_ENABLED=true` 启用；启动时未启用则不注册，运行时也再次检查开关。错过计划按既有调度器的 `missed: once` 处理。任务经同名来源队列与 worker 执行，保留任务记录和快照审计；刷新时间不是官方数据发布时间。其他官方新闻订阅使用原有 worker 采集机制。

政策情景研究在上海时间 18:15 入队，仅字面值 `MODEL_CALLS_ENABLED=true` 启用，也可在后台通过 `POST /api/admin/markets/research` 提交 `{ reason }` 发起。生成使用现有摘要模型配置、付费回执与预算熔断；页面读取不调用模型。发布与回执完成同事务提交，保留人工研究。

新闻评分保留七种内容类型和五维加权结构。所有栏目都参加评分，没有按市场名称任意加分；`industry/selection.ts` 数值门槛未改。上线前使用人工标注的金融样本重新校准。站名为 AIQUANT；条款与隐私页面仍需站长确认后上线。
